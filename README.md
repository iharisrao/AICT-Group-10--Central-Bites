# 📖 Project Description
**Central Bites** is a website we built to help people find the best places to eat. Our goal was to make a simple, good-looking "food guide" that works on both computers and phones.

**What this website can do:**
Show Restaurant Cards: Every restaurant has its own "card" that shows its picture, name, star rating, and how far away it is.

**Check if Open:** The website is smart! It looks at the clock and shows a Green "OPEN" badge or a Red "CLOSED" badge so users know if they can go there right now.

**Search and Filter:** Users can type the name of a restaurant in the search bar or click "Mood" buttons (like Fast Food or Casual) to find exactly what they want.

**Help You Choose:** We added a fun "Spin the Plate" button that picks a random restaurant for you if you can't decide where to eat.
